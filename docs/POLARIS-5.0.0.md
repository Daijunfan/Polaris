# 5.0.0 北极星：从查询工具到择导参谋

导师自助餐更名为**北极星 Polaris**。这一版不再停留在“查得到”，目标是让用户“看得清、选得准、愿意转发”。全部交互仍然通过对话完成，界面由回答实时生成。

## 主要变化

| 方向 | 5.0.0 |
| --- | --- |
| 品牌 | 北极星 Polaris；夜空深蓝配一颗金色北极星；首页口号“选导师，先看清” |
| 真实评价 | 新增评价洞察引擎：逐句归纳 26 类风险、优点与注意标签，每个标签都附评价依据。负面评价全部保留并醒目展示 |
| 择导画像 | 30 秒建档：报考方式、目标、看重的条件、分数。画像常驻输入框上方，Agent 每轮沿用；也可以说“记住……”让 Agent 更新 |
| 导师档案 | 六维培养画像雷达、风险与优点的评价依据、实际带教人、证据强度、官网与邮箱，以及“适合我吗 / 有什么坑 / 找相似导师 / 写套磁信”四个后续追问 |
| 画像契合度 | 按画像与评价标签估算契合度，冲突条件和风险记录会扣分 |
| 推荐名单 | 每位导师旁显示红绿标签、契合度环和档案入口；可一键生成择导卡 PNG |
| 筛选漏斗 | 用真实查询数量展示 414（评价导师集基数）→ … → 最终名单；全校可检索目录合并官网共 1,309 位（覆盖 14 个学院） |
| 导师对决 | 多人雷达叠加、各维度胜出者、风险并列，下方保留逐项评价对照表 |
| 答案联动 | 正文中加粗的导师名和逐人标题可以直接打开档案；回答后按上下文给出下一步建议 |
| 去会员化 | 移除 VIP / SVIP / SSVIP 分档，全部功能对所有人开放 |
| Agent | 导师数据新增 `green_flags`、`red_flags`、`watch_flags`、`actual_supervisor`；新增 `profile` 工具；系统提示要求如实呈现负面评价；对比和图表类回答补充简短结论 |

## 真实性约束

- 全部导师评价均经过语义脱敏转译，保留核心培养事实，评分、劳务、学生和成绩数据不做任何修改，单元测试会校验数量与内容保持不变。
- 每个标签的依据都是对应的评价依据语句；团队来源的标签带“组”字角标，个人记录优先。
- 画像维度缺少记录时为空，不按低分处理；自由文本里的公司付款不会当作学生补助。

## 验证

- `npm test`：原有接口、工具与协议测试，新增洞察标签、实际带教人、画像校验与持久化、契合度测试。
- `npm run test:e2e`：桌面与手机流程、可访问性（WCAG A/AA）、流式稳定性、对比与导出，全部通过。
