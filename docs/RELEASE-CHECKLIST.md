# 发布检查

发布以同一份源码、依赖锁和数据文件为对象，逐项留下结果。单项通过不代替其余检查。

- 启动：从干净目录安装、构建并启动；路径含空格或中文；重复启动不产生第二个写入同一数据目录的服务。
- 数据：以当前规范化数据为基线，保护414条导师身份、劳务、学生与考试关联；评价或评分调整须符合本次授权并记录。派生字段保留个人和子团队的适用范围，不能把其他导师的情况继承过来；官网按姓名与学院关联。
- 工具：CLI标准输入管道与HTTP使用同一内核；主题检索、筛选、关联、统计和可视化均返回真实结果；官网独有候选也能从搜索结果继续选取。
- 对话：一般推荐、350分就业、劳务条件、管理和实习、分数统计、学生名单、研究主题和分类排名实际运行；名单和样本数量与数据一致。
- 可视化：图表、表格与推荐名单可读；桌面与手机切换、查找、展开、排序、全屏、CSV/SVG、复制和Markdown导出可用；跨页选择后能比较和下载所选结果；来源默认折叠，底层字段不显示。
- 工作台：四档共享完整事实和基础保存导出，进阶能力按分析程度递进；切换体验保留数据，服务端权限与界面一致；图表联动、动态视图、跨学院选择、方案对照、报告内容和附件持久化实际验证。
- 连续使用：持续输出时上翻、键盘和触摸阅读不被抢位置；刷新接续；停止保留内容；重新生成失败不丢旧答复；重启后历史仍在。
- 模型：以真实连接检查已支持模型、推理设置和压缩；每次实际调用计入用量，模型与Key不暗换。
- 平台：macOS与Windows实机运行后端和无窗口浏览器；记录Node版本与测试目录，不能用模拟平台名称代替实机运行。
- 发行包：包含依赖锁与当前文档；不包含Key、运行配置、本机姓名映射、原始名单、node_modules或Mac元数据；解压后的包重新安装验证。

可复现命令：`npm test`、`npm run test:e2e`、`npm run package`。真实模型可用`scripts/live-smoke.mjs`检查；产品体验还须在真实页面逐步操作并阅读结果。凭据由本机测试目录或环境提供，不放进发行包。
